# openAPI

OpenAPI specs and API design / documentation experiments.

## Stack

Turborepo, TypeScript

## Getting started

```bash
git clone https://github.com/ANSHSINGH050404/openAPI.git
cd openAPI
bun install
bun run dev   # or: bun run start
```
